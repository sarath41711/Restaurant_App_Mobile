# Restaurant App Mobile Application

A modern Android-based Restaurant Mobile Application developed to provide users with a seamless food ordering and restaurant browsing experience. The application allows users to explore food items, view restaurant details, and manage orders through an interactive mobile interface.

## Features

* User-friendly mobile interface
* Browse restaurant menu items
* Food item listing with images and prices
* Add to cart functionality
* Order management
* Responsive Android UI design
* Smooth navigation between screens

## Tech Stack

* **Language:** Kotlin
* **Framework:** Android SDK
* **Build Tool:** Gradle Kotlin DSL
* **IDE:** Android Studio

## Installation Steps

1. Clone the repository:

```bash
git clone https://github.com/sarath41711/Restaurant_App_Mobile.git
```

2. Open the project in Android Studio.

3. Sync Gradle files.

4. Run the application on:

   * Android Emulator
   * Physical Android Device

## Requirements

* Android Studio
* Android SDK
* Gradle
* JDK 17 or above
